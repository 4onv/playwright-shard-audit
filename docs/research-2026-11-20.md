# GitHub research for November 20, 2026

The targeted Chicago day ran from 2026-11-20 06:00 UTC through 2026-11-21 06:00 UTC, end exclusive. Repo totals and the rolling Trending page were observed separately on November 21. The rolling list included OpenSRE, a CI/CD reliability tool. It is context for developer interest, and it cannot reconstruct November 20 ranks or star gains. [GitHub Trending](https://github.com/trending)

All 21 tracked 4onv projects had zero stars, forks, and public issue or pull request counts at the API observation. Comparable observations show no traction leader, so the selection favored a concrete workflow and a demonstration that exercises the actual upstream interface.

I selected Playwright Shard Audit because job counts and individual success statuses cannot establish coverage across the whole matrix. The Playwright reporter provides selected test identities and the declared slot. The tool can therefore demonstrate both a correct three-shard partition and a reused-slot failure without running browsers. This is separate from CheckCanary, which asks if a verifier catches deliberate defects.
